# 非遗剪纸小游戏 · 纸上生花

一个纯前端（HTML5 + Canvas）的中国非遗剪纸主题小游戏，无需任何构建步骤或外部资源，
双击 `index.html` 即可在浏览器中游玩。

**线上版**：https://ttyunss.github.io/papercut-game/

## 游戏结构

**开始界面** → **主菜单**（四选一）：

| 模块 | 内容 |
| ---- | ---- |
| 📖 故事背景 | 非遗剪纸科普：南北朝团花、2009 年入选人类非遗名录、南北流派、窗花寓意，配三幅示意图 |
| ✂ 开始游戏 | 三个难度关卡（见下） |
| 🪟 自由剪纸 | 红纸自由折（横/竖/对角，最多 4 折）→ 剪刀自由剪 / 戳孔 → 展开对称窗花，可保存 PNG |
| 🚪 退出游戏 | 告别页，提示进度已保存 |

## 三大关卡

| 关卡 | 主题 | 面向 | 玩法 |
| ---- | ---- | ---- | ---- |
| 第一关 · 童心巧手 | 儿童益智 | 小朋友 | **萌新拼图**：把剪纸碎片拖回虚线剪影，碎片大、数量少、色彩明快 |
| 第二关 · 指尖飞花 | 青年普通 | 青年 | **折纸剪纸**：折三折 → 沿虚线剪开（6 条细线）→ 展开绽放窗花 |
| 第三关 · 岁月静好 | 老年闲玩 | 长辈 | **折纸剪纸**：折两折、大线条粗容差、不限时慢慢剪 |

第一关 3 张拼图图案（梅花/小屋/小鱼等共 9 张备用图案库），二、三关为程序生成的对称窗花。

## 玩法说明

- **折纸**：点击闪烁的虚线折痕，红纸对折（可点工具栏"跳过折纸"直接开剪）；
- **剪纸**：按住鼠标/手指沿米白虚线拖动剪刀，"嚓嚓"推进；偏离虚线会累计失误影响星级；
- **展开**：全部剪完后窗花旋转绽放，星级按偏离次数评定（0 次 = 三星）；
- **自由剪纸**：左侧工具栏折纸 → 剪/戳孔 → 「展开窗花」看 2ⁿ 对称成品 → 保存图片；
- 拼图关支持拖放与点选-点放两种操作，同形碎片可互换，星级由失误/提示决定。

## 技术说明

- 纯原生实现：Canvas 2D 渲染、Pointer Events（鼠标/触屏统一）、WebAudio 实时合成音效
  （含剪刀噪声脉冲、折纸扫音、绽放琶音）与五声音阶背景拨弦，无任何外部资源依赖；
- 图案几何由参数化形状库程序化生成（`js/patterns.js`，坐标系 900×640）；
  折剪数据（折法序列 + 剪裁虚线 + 容差）也在同一文件，Node 可校验；
- `js/cutplay.js` 折纸剪裁引擎（折纸动画/剪刀推进/镜像展开）；`js/freecut.js` 自由剪纸；
- 进度与星级、静音偏好保存在 localStorage；
- `verify.js`（Node 运行）校验全部图案与折剪数据，`--render`/`--dump` 可输出渲染预览；
- URL 调试模式：`#menu`、`#story`、`#free`、`#patterns=1`、`#cut=2|3`（可加 `:cut`/`:unfold` 跳阶段）、
  `#preview=图案ID`、`#auto=图案ID`。

## 目录结构

```
papercut-game/
├── index.html        页面骨架（标题/菜单/故事/关卡/自由剪纸/告别页）
├── css/style.css     剪纸风视觉（红纸/宣纸底/楷体/老年关大字号）
├── js/patterns.js    形状库 + 拼图图案 + 折剪数据（纯数据，Node 可校验）
├── js/audio.js       WebAudio 音效（拼图 + 折剪两套）
├── js/cutplay.js     折纸+剪刀玩法引擎（二、三关）
├── js/freecut.js     自由剪纸模式
├── js/game.js        状态机与总调度
├── verify.js         数据校验与渲染预览脚本（Node）
├── deploy.ps1        GitHub Pages 部署脚本（需 Token 参数）
└── shots.ps1         无头浏览器截图脚本（自动化验证用，可删）
```

## 本地运行

直接双击 `index.html`，或 `start index.html`。
校验：`node verify.js --render`
