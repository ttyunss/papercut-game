# 纸上生花 · 剪纸拼图小游戏

一个纯前端（HTML5 + Canvas）的中国剪纸主题拼图游戏，无需任何构建步骤或外部资源，
双击 `index.html` 即可在浏览器中游玩。

## 三大关卡

| 关卡 | 主题 | 面向 | 特点 |
| ---- | ---- | ---- | ---- |
| 第一关 · 童心巧手 | 儿童益智 | 小朋友 | 碎片大、数量少、色彩明快，吸附更宽松 |
| 第二关 · 指尖飞花 | 青年普通 | 青年 | 碎片更多更精细，带计时挑战与最佳纪录 |
| 第三关 · 岁月静好 | 老年闲玩 | 长辈 | 传统窗花纹样（寿桃/福字/双鱼），不限时间、大字号、大碎片 |

每关 3 张剪纸图案，共 9 张：梅花开春、暖暖小屋、快乐小鱼 · 大红灯笼、花间蝴蝶、
荷塘清趣 · 仙桃献寿、福到我家、年年有余。

## 玩法

- 把底部"剪纸碎片"托盘里的碎片，**拖到**画板上对应的虚线剪影处松手；
- 也可以**先点碎片、再点剪影**两段式放置（对触屏更友好）；
- 形状相同的碎片（五片花瓣、两朵祥云等）可以**互相替换**位置；
- 拿不准时点 **提示**，会金光高亮一块碎片和它的剪影（影响星级）；
- 全部拼完触发纸屑庆祝；星级由失误与提示次数决定（0 失误 0 提示 = 三星）；
- 第二关有计时，结算显示用时与最佳纪录。

## 技术说明

- 纯原生实现：Canvas 2D 渲染、Pointer Events（鼠标/触屏统一）、WebAudio 实时合成
  音效与五声音阶背景拨弦，无任何图片、字体或音频文件依赖；
- 图案几何全部由参数化形状库（`js/patterns.js`：圆/椭圆/圆角矩形/星形/花瓣/叶片/
  Catmull-Rom Blob 等）程序化生成，坐标系 900×640；
- 进度与星级、静音偏好保存在 localStorage；
- `verify.js`（Node 运行）对图案数据做结构校验，并可用 `--render` / `--dump`
  输出 ASCII / 数值渲染预览，`--only=L3-2` 可指定单个图案；
- 支持 URL 调试模式：`#preview=L2-1`（直接全摆放查看成品）、`#patterns=2`（直达选图页）。

## 目录结构

```
papercut-game/
├── index.html        页面骨架与弹窗结构
├── css/style.css     剪纸风视觉（红纸 / 宣纸底 / 楷体 / 老年关大字号）
├── js/patterns.js    形状库 + 9 个关卡图案定义（纯数据，Node 可校验）
├── js/audio.js       WebAudio 音效合成（拾取/吸附/错误/胜利/背景拨弦）
├── js/game.js        状态机、渲染、输入、吸附判定、星级与存档
├── verify.js         图案数据校验与渲染预览脚本（Node）
└── shots.ps1         无头浏览器截图脚本（自动化验证用，可删）
```

## 本地运行

直接双击 `index.html`，或：

```
> start index.html
```

可选校验：`node verify.js --render`
